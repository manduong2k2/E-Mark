Component Flow
==============

User Message
    ↓
Chatbot.jsx (handleSendMessage)
    ↓
API Response with attachments
    ├─→ reply: "Text response"
    └─→ attachments: { intent: "products", data: {...} }
    ↓
Chatbot.jsx (parseAttachments)
    ├─→ Add text message
    └─→ Add component message
    ↓
AttachmentRenderer.jsx
    ├─→ Check intent type (product/category/brand/vendor)
    ├─→ Check if data is list or detail
    └─→ Select and render appropriate component
    ↓
ProductCard / ProductList / CategoryCard / CategoryList / etc.
    ↓
Visual display in chat bubble


Key Features
============

✓ Automatic component selection based on intent
✓ Smart list vs. detail detection
✓ Two render modes:
  - Card: Single item display (optimized for chat)
  - List: Multiple items with pagination
✓ Responsive design (fits in 380px chat window)
✓ Styled to match chatbot theme
✓ Empty state handling
✓ Graceful error handling
✓ Easily extensible for new entity types
✓ Fully backward compatible


Integration Steps for Backend
==============================

1. Ensure API returns format:
   {
     success: true,
     data: {
       reply: "...",
       attachments: {
         intent: "products",
         data: { ... }
       }
     }
   }

2. For single items: Make sure data is object with id, name, etc.
3. For lists: Wrap items in data.data array with pagination fields
4. Test with examples in INTEGRATION_GUIDE.md
